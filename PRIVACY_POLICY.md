# VelocityDL Bridge Privacy Policy

Last updated: July 6, 2026

## Overview

VelocityDL Bridge is a Chromium browser extension that helps users send downloads, page captures, and detected media URLs from the browser to the locally installed VelocityDL desktop application.

This extension does not operate a cloud service for user accounts, analytics, advertising, or remote data collection. Its purpose is to pass user-requested browser download and media context to the user's own local VelocityDL installation through Chrome native messaging.

## What the extension accesses

Depending on the page and the feature the user enables, the extension may access:

- page URLs
- media URLs
- download URLs
- referrer information
- basic request headers needed for download handoff
- the active tab and related tab metadata
- user-selected extension settings
- temporary diagnostic and heartbeat state

## How data is used

The extension uses this information only to:

- detect downloadable files and media streams
- show the optional scan overlay on pages the user visits
- let the user send selected downloads or captures to VelocityDL
- verify whether the local VelocityDL desktop app is available
- store the user's local extension preferences
- provide local troubleshooting diagnostics

## How data is shared

The extension does not sell user data.

The extension does not transfer user data to remote developer-controlled servers for analytics, advertising, profiling, or unrelated purposes.

When the user uses VelocityDL Bridge, relevant download or capture data may be sent only to:

- the websites the user is already visiting as part of normal browsing
- the user's locally installed VelocityDL desktop app through Chrome native messaging

## Local storage

The extension stores limited local data inside the browser, including:

- takeover and context-menu preferences
- scan capture mode preferences
- active scan overlay state
- recent local debug state such as heartbeat and scan diagnostics

This data is stored locally in the browser and is used only for extension functionality.

## Remote code

VelocityDL Bridge does not download and execute remote code.

All extension JavaScript included in the extension package is bundled with the extension itself. The extension does not use externally hosted executable scripts or remotely executed Wasm as part of extension logic.

## Third-party access

VelocityDL Bridge does not sell or transfer user data to third parties except where necessary for the extension's single purpose as described above.

VelocityDL Bridge does not use user data to determine creditworthiness or for lending purposes.

## User control

Users can:

- disable or remove the extension at any time
- disable browser takeover features in the extension or app settings
- clear the extension by removing it from the browser
- disable the VelocityDL desktop integration by uninstalling or disconnecting the local app

## Contact

For questions about this privacy policy, contact the publisher through the contact information listed on the Chrome Web Store publisher profile.
