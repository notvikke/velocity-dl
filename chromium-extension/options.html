Troubleshooting

  • If scan overlay was enabled on an already-open page, VelocityDL now retries script injection without requiring a full page reload.
  • Keep the native host name at com.velocitydl.native_host.
  • If multiple unpacked VelocityDL copies are loaded in Chrome, disable the unused ones.
